# Spring Security evals

Evals for [Spring Security](https://spring.io/projects/spring-security): authentication, authorization, and protection for Spring applications.

| Eval | Type | Difficulty | What it tests |
|---|---|---|---|
| [000-lockdown](000-lockdown) | build | medium | A stateless SecurityFilterChain with public reads, authenticated writes, and an ADMIN area |
| [001-method-security](001-method-security) | fix | medium | An authorization bypass through a second code path, fixed with method-level security instead of another web-layer patch |

Have an idea for one? Open a [benchmark proposal](../../../../issues/new?template=benchmark-proposal.yml) or see [CONTRIBUTING.md](../../CONTRIBUTING.md) to build it.
